# Content Performance Archetypes

I analyzed 50,000 FlyRank content items using unsupervised machine learning to identify broader content-performance patterns.

The analysis used 14 signals covering search visibility, website traffic, acquisition, and user engagement. After standardizing the data, I evaluated K-Means clustering from K = 2 to K = 6 using silhouette scores.

K = 2 produced the strongest result, separating the content into Higher-Performance and Lower-Performance archetypes. The results are observational, but they provide a useful starting point for content analysis and prioritization.
