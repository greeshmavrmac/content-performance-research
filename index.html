Identifying Content Performance Archetypes Using Unsupervised Machine Learning

FlyRank ML Internship Capstone Research

Abstract

This study investigates whether unsupervised machine learning can identify meaningful patterns in content performance using search visibility, website traffic, and user engagement signals.

Data from the FlyRank ML Internship Warehouse were analyzed using the fact_content_daily_performance dataset. Daily observations were aggregated by content identifier, producing a sample of 50,000 content items.

Fourteen numerical features representing search, traffic, acquisition, and engagement performance were selected for analysis. After data cleaning and feature standardization, K-Means clustering was evaluated using different numbers of clusters from two to six.

Research Question:
Can unsupervised machine learning identify distinct content performance archetypes from search visibility, traffic, and user engagement signals?

The final analysis identified two broad content archetypes: Higher-Performance Content and Lower-Performance Content.

Keywords: Content performance, K-Means clustering, unsupervised learning, search analytics, web analytics, content archetypes.

1. Introduction

Digital content generates multiple forms of performance data, including search impressions, clicks, search position, pageviews, sessions, traffic sources, and user engagement signals.

Analyzing these metrics individually can make it difficult to identify broader patterns across large collections of content.

Unsupervised machine learning provides an approach to this problem. Instead of manually defining what constitutes successful or unsuccessful content, clustering algorithms can group content items according to similarities in their observed performance characteristics.

The objective of this study is to investigate whether content items can be grouped into meaningful performance archetypes using search, traffic, and engagement metrics.

2. Data and Feature Selection

This study used data from the FlyRank ML Internship Warehouse. The analysis focused on the fact_content_daily_performance table, which contains daily observations of content performance across search and analytics-related metrics.

A sample of 50,000 content items was created by aggregating observations using content_hash_id.

The content_hash_id variable was used only to identify and aggregate individual content items. It was not included as a clustering feature.

3. Methodology

3.1 Data Preparation

The dataset was aggregated by content_hash_id to create content-level observations. The resulting dataset contained 50,000 content items and 14 numerical performance features.

Missing values in avg_position were replaced using the median observed position.

3.2 Feature Standardization

The selected variables had substantially different scales. StandardScaler was used to ensure that variables with larger numerical values did not dominate the clustering process.

3.3 Cluster Selection

K-Means clustering was evaluated using values from K = 2 to K = 6. The silhouette score was used to evaluate cluster separation.

Number of Clusters Silhouette Score

Result: K = 2 produced the highest silhouette score and was selected for the cluster-count experiment.

3.4 Preprocessing Comparison

Two preprocessing approaches were compared:

  • Baseline: Feature standardization
  • Alternative: Log transformation followed by standardization
Approach Silhouette Score
Standardization Only 0.8157
Log Transformation + Standardization 0.3912

The standardization-only approach produced the stronger result in the evaluation procedure and was retained for the final analysis.

5. Discussion

The results demonstrate that the selected performance signals contain sufficient structure to separate the analyzed content into two broad archetypes.

The Higher-Performance Content group consistently showed stronger observed performance across search visibility, website traffic, and engagement metrics.

Search Visibility and Traffic

The higher-performing group had substantially more impressions and clicks, together with far more organic sessions.

Search Position

The higher-performing group had an average search position of 10.39 compared with 41.13 for the lower-performing group. Because lower position values indicate stronger ranking positions, this group demonstrated better observed search visibility.

Important: These findings represent observed associations. The clustering analysis does not establish causal relationships.

6. Limitations

  1. The analysis used a sample of 50,000 content items rather than the entire warehouse.
  2. Results depend on the selected features and preprocessing methods.
  3. Different clustering algorithms could produce different group structures.
  4. Two clusters do not imply that only two content-performance patterns exist.
  5. The analysis is observational and cannot establish causality.

7. Conclusion

This study investigated whether unsupervised machine learning could identify meaningful content performance archetypes using search visibility, traffic, and user engagement signals.

A sample of 50,000 aggregated content items was analyzed using 14 numerical performance features. Cluster configurations from two to six were evaluated using silhouette scores.

Final Result:
  • Higher-Performance Content: 34,372 items (68.74%)
  • Lower-Performance Content: 15,628 items (31.26%)

Overall, the results show that unsupervised clustering can identify broad and interpretable patterns in observed content performance. These archetypes may be useful for content analysis and prioritization, but they should not be interpreted as causal evidence.

8. Ranked Recommendations

  1. Prioritize content with weak search visibility. Investigate content with low impressions and clicks.
  2. Review content with weak organic traffic. Investigate search relevance and discoverability.
  3. Examine low-engagement content. Review structure, relevance, readability, and user experience.
  4. Use higher-performing content as a comparison group. Compare successful and lower-performing content characteristics.
  5. Repeat the analysis on newer data. Content performance can change over time.
